# K-컬처 리얼맵 · frontend (React Native / Expo)

피그마 최종본(`design-reference/` 11장, 384×824 기준)을 그대로 코딩한 프론트엔드입니다.
백엔드(`kculture/` 자바 프로젝트)는 건드리지 않았고, 이 폴더는 완전히 독립된 Expo 프로젝트입니다.

## 처음 실행하는 법

이 프로젝트 파일은 코딩 에이전트가 만들었지만, `npm install`은 보안 정책상
에이전트 환경에서 직접 실행할 수 없어서 사용자가 본인 터미널에서 한 번 실행해줘야 합니다.

```bash
cd frontend
npm install
npx expo install --fix   # 설치된 Expo SDK 버전에 맞게 의존성 버전을 자동 보정
npx expo start
```

`npx expo start`가 뜨면 Expo Go 앱으로 QR코드를 스캔하거나, `a`를 눌러 안드로이드
에뮬레이터(갤럭시 S25 기준 해상도로 맞춰 디자인함)에서 열어보면 됩니다.

## 폴더 구조

```
src/
  theme/        색상·타이포·에셋 토큰 (colors.ts, typography.ts, assets.ts)
  components/   공용 UI 부품 (버튼, 카드, 칩, 탑바, 지도 플레이스홀더 등)
  screens/      화면 11개 (디자인 원본과 1:1 매칭)
  navigation/   RootNavigator(온보딩→탭) / MainTabNavigator(5탭) /
                HomeStackNavigator, QuestStackNavigator(퀘스트 진행 흐름)
  data/mock.ts  백엔드 연동 전까지 화면을 채우는 목업 데이터
assets/         폰트(조선100년체) · 아이콘 · 배경 PNG
design-reference/  피그마에서 받은 원본 스크린샷 (코딩 시 참고용, 앱에는 포함 안 됨)
```

## 백엔드 연동 시 참고

- `src/data/mock.ts`의 각 배열 구조가 앞으로 API 응답을 매핑할 때의 기준 모양입니다.
- 백엔드 응답 스키마가 이 구조와 다르면 백엔드를 먼저 고치지 말고, 프론트에서
  매핑 함수를 추가하는 방향으로 진행해주세요 (백엔드 수정은 별도 상의 후 진행).

## 디자인 원본과 다르게 보일 수 있는 부분

디자인 PNG를 그대로 코딩하라는 요청에 따라, 원본에 있던 아래 표기들도 오타 그대로
남겨뒀습니다(임의로 고치지 않음):

- 분석 화면: "AI가 찾은 한국척 요소" (→ "한국적"의 오타)
- 분석 화면 배지 5개 중 4번째가 보라색인데 라벨이 "건축"으로 중복 표기됨 (원래는 "의례"로 추정)
- 퀘스트 메인: 진행 표시가 "3단계 중 1단계" ("완료" 없이 표기)
- GPS 화면: "100년 컨 인천으로 이동 중..." (→ "전"의 오타로 추정)
- 미션 화면 CTA 버튼: "퀘스트 시작하기" (완료 버튼이 아니라 원본 그대로)

실제 서비스에 반영하기 전에 원본 디자이너와 확인 후 필요하면 알려주시면 바로 고치겠습니다.
